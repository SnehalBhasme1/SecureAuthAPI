# JWT Authentication API 🔐

A backend authentication system built using **Java, Spring Boot, Spring Security, JWT, and MySQL**.

## Features
- User Registration API
- Login API
- BCrypt Password Encryption
- JWT Token Generation
- Secure Authentication Flow
- MySQL Database Integration
- REST API Testing using Postman

## Tech Stack
- Java
- Spring Boot
- Spring Security
- JWT
- MySQL
- Gradle
- Postman

## API Endpoints

### Register User
POST /auth/register

### Login User
POST /auth/login

## Project Purpose
This project was built to understand secure authentication, JWT-based token generation, password hashing, and backend security concepts.
